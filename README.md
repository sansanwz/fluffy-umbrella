# fluffy-umbrella
# 热量计算器
网页版营养热量计算器，前端原生HTML+JS实现，无需后端。

## ✨功能
- 录入食物名称、重量、每100g热量、蛋白质含量
- 自动计算该食物总热量与总蛋白质
- 浏览器本地持久化保存历史记录，刷新页面记录不丢失
- 支持单条删除记录、一键清空全部历史

## 📌在线访问

## 🛠️技术栈
HTML + JavaScript，纯前端项目，数据保存在浏览器localStorage。
